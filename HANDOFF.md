## 1. The goal

vDAA (virtual Dr. Anne Anderson) is a financial literacy app and economy simulation for Mr. Tang's high school FinTech courses in Alberta (FinTech 10, and FinTech 20/30).

It has two halves that share one login:

- **The Learning Road**: short self-paced lessons (cards, then questions that check themselves), written from his course outlines. A finished level pays a small amount of in-game money.
- **The town**: a persistent virtual economy. Each student has a pseudonymous account, a job and pay stubs, bills, a bank, savings, credit, housing, insurance, an investment exchange, businesses, and a life that ages one month per class day. Every block plays in the same economy. Each building is a module tied to the program of studies and switched on per course.

What "good" means: students practise real money decisions with consequences they can see, the teacher controls pace and what is open, the economy stays balanced (the sim proves it), student data stays private, and it costs $0 to run.

The long plan and his original decisions are in `PLAN.md`. Do not read it end to end; its headings tell you which part you need.

## 3. How to run things

```bash
npm start            # http://127.0.0.1:3020 (PORT, DATA_DIR to change)
npm test             # node --test "test/*.test.js", about 3 minutes. NEVER bare `node --test`.
npm run sim -- --months=60 [--bots=300] [--teacher] [--seed=1]   # the economy simulation
```

- Zero dependencies: Node 24 or newer and `node:sqlite`. Do not add a package.
- Work in a git worktree (`git worktree add .worktrees/<name> -b <branch> main`), merge to `main`, tag, remove the worktree.
- Tests live flat in `test/`. A test in a subfolder is not run.
- Local previews are in `.claude/launch.json`: `vdaa` on 3020 (data in `data/`) and `vdaa-demo` on 3039 (dev mode, data in `data/demo/`, empty until you make a demo teacher and class). A module's UI files are versioned at server start, so restart the preview after changing them.
- **Never run two full suites at the same time** (they fail each other). Editors run only the test file for their change; the orchestrator runs the full suite once, before a merge.
- Commits end with `Co-Authored-By: Claude Fable 5.2 <noreply@anthropic.com>` (an editor on Sonnet uses its own model name).

**Deploy** is `../deploy-vdaa.sh`. It ships the working tree of this folder. The live branch is `release-pilot`, not `main` (it has no section 6), so: cherry-pick the code commits (not docs) onto `release-pilot` in a worktree, run the full suite there, remove the worktree, stop the preview, `git checkout release-pilot` here, run the script in the background, check the live site, `git checkout main`, tag both branches. Do not run the script for any other reason, such as to read its output. It backs up the database first and rolls back if the new build does not answer. **Never deploy without Mr. Tang saying "deploy" in that conversation.** Server details: `../GCP-HANDOFF.md` and the script's header.

## 5. Rules that must not break

1. **Privacy by design.** Accounts are teacher-issued pseudonyms with PINs. No names, no emails, nothing that identifies a student. `PLAN.md` section 8.
2. **Money moves only through `lib/ledger.js`.** The ledger audit must be OK every month of a sim.
3. **Time comes only from the clock** (`lib/clock.js`), never `Date.now()` in `lib/` or `modules/`.
4. **No random rewards.** Errands and lesson pay are fixed amounts. Bots use `k.dice` (a hash) or the sim's seeded `random`; prices and other draws come from a per-world secret.
5. **Never edit a migration that has shipped.** Add a new one.
6. **Lesson facts are his to confirm.** Every unit has a `modules/learn/content/REVIEW-*.md` listing its facts. Figures come from his outlines or from a pinned company file (`modules/learn/companies/*.js`), never invented in passing.
7. **Canadian and Alberta context**, plain language a Grade 10 student reads easily, and pages credit "Mr. Tang", never a tool.
8. **Keep `main` green and deployable.** Prove a change: the smallest test that fails without it, then the full suite before a merge.
9. A file split is move-only and proved with `scripts/split-moved-only.mjs` and `scripts/split-shape.mjs` (`docs/README.md`, "Splitting a large file").
10. **Art.** The ComfyUI gateway password is in the Keychain item `vdaa-comfystudio`: the tools read it; never read or print it yourself. TLS trusts only the pinned certificate `design/comfystudio.pem`; re-pin only when he confirms. Never use mascot seeds 8101-8104. Reference photos with people stay out of `design/refs`. The Agora art is not shown to students until the school's Indigenous education lead has reviewed it.
11. **Clean room.** The Learning Road was inspired by trenches.academy. Copy none of its text, questions, art, names or code. Lesson writers and verifiers do not open `replica/`.
12. **Secrets.** On the live site the teacher setup token and passphrase are his to type. A local demo login you create goes in a file under `data/` (ignored by git), never in a reply.
